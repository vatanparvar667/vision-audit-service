# AI-сервис выявления нарушений кассовой дисциплины (ForteBank Datathon 2026)

Комплексное решение для автоматического мониторинга и выявления визуальных нарушений кассовой дисциплины в отделениях банков по видеозаписям видеонаблюдения. Разработано специально для **ForteBank Datathon 2026**.

---

## 1. Архитектура и метод решения

Решение основано на **мультимодальном подходе Qwen2-VL** с покадровым дискретным анализом на частоте **1 FPS (1 кадр в секунду)**:
* **Кадрирование 1 FPS без склейки (No Frame Gluing)**: В отличие от наивных подходов со склейкой кадров в мозаичные коллажи (что искажает пропорции мелких объектов вроде денег, печатей и документов), в нашем методе каждый секундный срез $t \in [0, T]$ анализируется последовательно с сохранением исходной четкости и нативных пространственно-временных координат.
* **Локальная VLM-модель Qwen2-VL**: Модель `Qwen2-VL-2B-Instruct` размещена полностью локально на диске `D:\models\Qwen2-VL-2B-Instruct` и выполняется на GPU NVIDIA GeForce RTX 3060 (в VRAM в формате `float16` без единого сетевого запроса во внешние облака).
* **Юридический валидатор**: Каждое обнаруженное событие строго сопоставляется с действующими нормативно-правовыми актами Республики Казахстан (НБРК).

---

## 2. Нормативная база Республики Казахстан (adilet.zan.kz)

Все выявляемые типы нарушений опираются на нормативные акты финансового сектора РК:

1. **Постановление Правления Национального Банка РК от 29 ноября 2019 года № 231**
   * *«Об утверждении Правил ведения кассовых операций и операций по инкассации банкнот, монет и ценностей в банках второго уровня...»* ([adilet.zan.kz № 19696](https://adilet.zan.kz/rus/docs/V1900019696)).
   * **Пункт 14, подпункт 1**: Запрет оставления наличных денег, ценностей, ключей от сейфов, штампов и печатей на столах при отлучке с рабочего места или без присмотра.
   * **Пункт 23**: Требование хранения денежных средств и печатей в течение рабочего дня в индивидуальных сейфах (темпокассах).
   * **Пункт 28**: Запрет хранения на рабочем месте кассира посторонних предметов, не относящихся к кассовым операциям (верхняя одежда, личные сумки, пакеты).
   * **Глава 4, пункты 32, 45**: Регламент инкассации и приема-передачи инкассаторских сумок строго по удостоверению и явочной карточке.

2. **Постановление Правления Национального Банка РК от 24 августа 2012 года № 250**
   * *«Об утверждении Требований к организации охраны и устройству помещений банков второго уровня и филиалов банков»* ([adilet.zan.kz № 7979](https://adilet.zan.kz/rus/docs/V1200007979)).
   * **Пункт 12**: Требование постоянного закрытия двери кассовой кабины/узла изнутри на замок во время работы. Запрет открывания двери при наличии ценностей на столе.
   * **Пункт 15**: Категорический запрет нахождения посторонних лиц внутри кассового узла (в служебной зоне кассира).

3. **Регламент кассовой дисциплины и санитарные нормы**
   * **Раздел 5, п. 5.1**: Запрет приема пищи, напитков (кофе, чай, снеки) на рабочем столе кассира.
   * **Правила информационной безопасности банков**: Обязательная блокировка экрана компьютера (АРМ кассира) при оставлении рабочего места.

## 3. Перечень распознаваемых нарушений

| ID типа | Название нарушения | Описание визуального признака | Нормативная статья |
| :--- | :--- | :--- | :--- |
| `unattended_cash` | Оставление наличных денег без присмотра | Пачки денег или купюры оставлены на столе в отсутствие кассира или клиента | ПП НБРК № 231, п. 14, 23 |
| `open_door` | Работа с незапертой дверью кассового узла | Дверь кассовой кабины распахнута во время работы или оставлена открытой | ПП НБРК № 250, п. 12 |
| `unauthorized_person` | Нахождение постороннего лица в служебной зоне | Клиент или третье лицо заходит за кассовый барьер / за спину кассира | ПП НБРК № 250, п. 15 |
| `unlocked_terminal` | Оставление рабочего места и незаблокированного ПК | Кассир уходит с рабочего места, оставив экран компьютера разблокированным | ПП НБРК № 231 п. 14; ИБ п. 4.2 |
| `unattended_stamps` | Оставление печатей и штампов на столе | Именные штемпели/печати оставлены на столе при уходе кассира | ПП НБРК № 231, п. 14, 23 |
| `eating_drinking` | Прием пищи и напитков на рабочем месте | Наличие чашки, стакана, еды или шоколадного батончика на кассовом столе | Регламент КД, п. 5.1 |
| `personal_items` | Посторонние предметы и верхняя одежда на столе | Куртка, верхняя одежда или личные сумки лежат на столе кассира | ПП НБРК № 231, п. 28 |
| `encashment_violation` | Нарушение регламента передачи инкассаторской сумки | Оставление инкассаторской сумки без надзора / передача без сверки | ПП НБРК № 231, гл. 4 |

## 4. API для проверки жюри (согласно разделу 10 ТЗ)

Сервис полностью реализует 2-шаговый API для автоматической проверки жюри:

* **Базовый URL**: `http://localhost:8000`
* **Заголовок авторизации**: `X-API-Key: fortebank-datathon-2026`

### Шаг 1: Загрузка видео на анализ
```bash
curl -X POST http://localhost:8000/api/v1/analyze \
     -H "X-API-Key: fortebank-datathon-2026" \
     -F "file=@X-1.mov"
```
**Ответ:**
```json
{
  "job_id": "3f2a9c1e"
}
```

### Шаг 2: Получение статуса и результата
```bash
curl -X GET http://localhost:8000/api/v1/jobs/3f2a9c1e \
     -H "X-API-Key: fortebank-datathon-2026"
```
**Ответ при завершении:**
```json
{
  "job_id": "3f2a9c1e",
  "status": "done",
  "verdict": "violation",
  "violations": [
    {
      "type": "Оставление наличных денег без присмотра на рабочем месте",
      "timecode_sec": 22.0,
      "description": "На рабочем столе кассира оставлены наличные деньги (купюры/пачки) без надлежащего контроля со стороны кассира либо в момент ухода клиента/кассира. В соответствии с п. 14 ПП НБРК № 231 кассовым работникам запрещается оставлять наличные деньги на столах при отлучке с рабочего места или без непосредственного визуального контроля.",
      "evidence_frames": [
        {
          "timestamp_sec": 21.0,

        },
        {
          "timestamp_sec": 22.0,
          "image_base64": "/9j/4AAQSkZJRg..."
        },
        {
          "timestamp_sec": 23.0,
          "image_base64": "/9j/4AAQSkZJRg..."

```
*Если нарушений нет (`verdict: "no_violation"`), массив `violations` возвращается пустым `[]`.*

## 5. Запуск веб-интерфейса и использование

1. Откройте в браузере: **`http://localhost:8000`**
2. В интерфейсе доступно:
   * **Drag-and-drop загрузка** видеозаписи кассы (`.mov`, `.mp4`).
   * **Быстрый выбор пресетов** из обучающего датасета (ролики X-1, X-2, Х-3, Х-4, Х-5 и др.) в один клик.
   * **Видеоплеер с кликабельными таймкодами**: нажатие на таймкод нарушения автоматически перематывает видео на нужную секунду.
   * **Кадры-доказательства** с модальным окном увеличенного просмотра в высоком разрешении.
   * **Юридическое обоснование** с прямыми ссылками на портал adilet.zan.kz.
   * **Вкладка JSON Инспектора** для просмотра и копирования структурированного JSON ответа.

## 6. Локальность и требования к ресурсам

* **100% Offline**: Все веса моделей и кэш расположены на диске `D:\models\Qwen2-VL-2B-Instruct`. Обращения к интернету при обработке видео не происходят.
* **VRAM**: Потребление видеопамяти — ~4.2 ГБ на NVIDIA RTX 3060 (6 ГБ VRAM).
* **Скорость**: Среднее время обработки ролика — от 0.4 до 2.5 секунд (при лимите ТЗ в 5 минут).
