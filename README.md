# AI-сервис выявления нарушений кассовой дисциплины (ForteBank Datathon 2026)

Комплексное решение для автоматического мониторинга и выявления визуальных нарушений кассовой дисциплины в отделениях банков по видеозаписям систем видеонаблюдения. Разработано специально для **ForteBank Datathon 2026**.

Решение полностью автономно (**offline**), развернуто на диске `D:` и не требует внешних облачных API.

---

## 1. Архитектура и метод решения

Решение основано на **мультимодальном подходе Qwen2-VL** с покадровым дискретным анализом на частоте **1 FPS (1 кадр в секунду)**:
* **Кадрирование 1 FPS без склейки (No Frame Gluing)**: В отличие от наивных подходов со склейкой кадров в мозаичные сетки/коллажи (что снижает пространственное разрешение мелких объектов вроде денег, печатей и удостоверений личности), каждый секундный срез анализируется нативно с сохранением геометрии и временных меток.
* **Локальная VLM-модель Qwen2-VL**: Модель `Qwen2-VL-2B-Instruct` размещена локально в `D:\models\Qwen2-VL-2B-Instruct` и выполняется на GPU NVIDIA GeForce RTX 3060 (VRAM в формате `float16` с динамическим управлением сегментами `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`).
* **Пространственная инвариантность (Spatial Invariance)**: В отличие от хрупких эвристик с жестко фиксированными координатами стола или кресла, модель семантически понимает сцену вне зависимости от угла обзора камеры и горизонтального отзеркаливания (horizontal flip).
* **Юридический валидатор**: Каждое обнаруженное действие строго привязано к статьям нормативно-правовых актов РК.

## 2. Актуальная нормативная база РК (Сверка законодательства на 17.10.2026)

Юридическая привязка в сервисе выполнена в соответствии со свежей сверкой законодательства Республики Казахстан:

### 2.1. Правила осуществления кассовых операций (Постановление Правления НБРК от 29.11.2019 № 231)
* **Пункт 20**: Ранее принятые деньги хранятся исключительно в запираемых устройствах (сейфах, темпокассах). На рабочей поверхности стола допускается нахождение **только денег обслуживаемого в данный момент клиента**.
* **Пункт 22**: Кассовому работнику **прямо запрещается покидать рабочее место до окончания обслуживания клиента**.
* **Пункт 12**: Личные вещи, верхняя одежда и личные деньги работников должны храниться **вне кассового узла**. Размещение курток, сумок, продуктов питания и напитков на рабочем столе кассира запрещено.
* **Пункты 7, 19 (пп. 1), 31 (пп. 1)**: Прием и выдача наличных осуществляются **только после проведения идентификации клиента и надлежащей проверки документов**, удостоверяющих личность (во исполнение требований Закона о ПОД/ФТ).
* **Пункты 15, 23, 75**: Порядок передачи ценностей между кассовыми работниками и строгий регламент доступа к ценностям.
* **Пункт 80**: Хранение ключей от сейфов и кодов доступа должно полностью исключать их несанкционированное использование (запрет оставления ключей в замочных скважинах сейфов).
* **Пункты 41–42, 57–59**: Обязательный полистный пересчет и проверка подлинности банкнот на приборах контроля. При выявлении сомнительных банкнот — составление акта в присутствии клиента и зав. кассой (п. 59).

### 2.2. Новый Закон о банках Республики Казахстан
* **Закон РК от 16.01.2026 № 258-VIII «О банках и банковской деятельности в Республике Казахстан»** (вступил в силу с 19.03.2026).
  > **Важно**: Прежний Закон от 31.08.1995 № 2444 утратил силу. Банковская тайна теперь регулируется **статьей 69** нового Закона № 258-VIII (вместо старой ст. 50). Оставление терминала незаблокированным квалифицируется как риск несанкционированного раскрытия банковской тайны (ст. 69).

### 2.3. Законодательство о ПОД/ФТ и персональных данных
* **Закон РК от 28.08.2009 № 191-IV (ПОД/ФТ)**: Меры надлежащей проверки клиентов до осуществления операций.
* **Закон РК от 21.05.2013 № 94-V «О персональных данных и их защите»** и **ст. 79 КоАП РК**: Административная ответственность за незаконное распространение и неправомерный доступ к персональным данным клиентов.
* **Уголовный кодекс РК**: ст. 189 (присвоение или растрата вверенного имущества), ст. 190 (мошенничество).
* **Постановление Правления НБРК от 24.08.2012 № 250**: Требования безопасности кассовых узлов (п. 12 — закрытие двери кассы на внутренний замок, п. 15 — запрет нахождения посторонних лиц в служебной зоне).

## 4. API для проверки жюри (Спецификация раздела 10 ТЗ)

Сервис полностью реализует 2-шаговый API для автоматической проверки жюри:
* **Базовый URL**: `http://localhost:8000`
* **Заголовок авторизации**: `X-API-Key: fortebank-datathon-2026`

### Шаг 1: Загрузка видео на анализ
```bash
curl -X POST "http://localhost:8000/api/v1/analyze" \
  -H "X-API-Key: fortebank-datathon-2026" \
  -F "file=@X-1.mov"
```
**Ответ:**
```json
{
  "job_id": "a1b2c3d4"
}
```

### Шаг 2: Получение статуса и результатов
```bash
curl -X GET "http://localhost:8000/api/v1/jobs/a1b2c3d4" \
  -H "X-API-Key: fortebank-datathon-2026"
```
**Формат ответа (JSON, Раздел 10 ТЗ):**
```json
{
  "job_id": "a1b2c3d4",
  "status": "done",
  "verdict": "violation",
  "violations": [
    {
      "type": "Прием наличных денег без предварительной проверки документов клиента",
      "timecode_sec": 10.0,

      "evidence_frames": [
        {
          "timestamp_sec": 9.0,
          "image_base64": "/9j/4AAQSkZJRg..."
```
